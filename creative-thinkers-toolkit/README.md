# Creative Thinking Tools

A set of 33 lightweight, standalone single-page apps for individual creative thinking.

## Run

Open `index.html` in a modern browser, then choose a tool. Each app is an independent HTML page with embedded CSS and JavaScript; there are no frameworks, package installs, accounts, or network calls.

## Features

- Guided prompts tailored to each technique
- Locally saved drafts (browser local storage)
- Reflection output with copy and text download controls
- Responsive, minimalist layout
- One special random-stimulus generator

To reset a tool's saved draft, use its Clear button.
